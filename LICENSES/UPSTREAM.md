# Upstream references and licenses

This lab intentionally builds on established open-source research/tooling rather than silently copying it.

## References

- `stefan-jansen/machine-learning-for-trading` — MIT License — research patterns for ML trading, multiple testing, strategy simulation and backtest diagnostics.
- `stefan-jansen/zipline-reloaded` — Apache-2.0 — maintained Zipline fork for event-driven backtesting.
- `quantopian/zipline` — Apache-2.0 — original Zipline project and historical reference.
- `X-DataInitiative/tick` — BSD-3-Clause — Hawkes-process / point-process modelling reference.

If code is copied or substantially adapted from an upstream project, preserve the upstream license/copyright notice in the relevant project folder and note the source in that branch README.
