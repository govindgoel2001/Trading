# AI Quant Lab

One repo, four branches, four serious AI × quant builds.

This repository is the umbrella for the AI Horizon quant projects. Each branch is a self-contained project with its own setup, provenance, and safety notes.

## Branches

- `prediction-market-arbitrage` — cross-venue / same-venue prediction-market edge research
- `information-diffusion` — news-to-price event modelling and Hawkes-style diffusion experiments
- `ai-strategy-search` — AI-assisted strategy generation, parameter sweeps, regime testing, and ranking
- `backtest-reality-check` — selection-bias / overfitting checks, deflated Sharpe, and robustness testing

## Quality bar

I only use established open-source projects with **500+ GitHub stars** as upstream references/dependencies for these branches. Where upstream code is reused or vendored, its original licence and attribution stay intact.
